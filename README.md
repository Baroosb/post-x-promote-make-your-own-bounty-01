Entry for the make.fun bounty [Promote make.fun's make-your-own-bounty post on X](https://make.fun/bounty/post-x-promote-make-your-own-bounty-01): one quote post of @makefunai's make-your-own-bounty announcement, with a photo of its own attached — https://x.com/0xBaros/status/2125169157855670514. Places go by the post's replies + reposts + quotes, read by the house from X. The post is named in `POST.json`; `main.ts` (Node 22, standard library only) validates it and copies it byte-for-byte to the output as `/output/POST.json`, which is all the program has to do.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
